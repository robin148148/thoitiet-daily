# Bản Đồ Cảnh Báo Thời Tiết Cực Đoan Việt Nam (GIS Web App)

Hệ thống bản đồ tương tác Web GIS cảnh báo thời tiết cực đoan trên toàn quốc, đồng bộ trực tiếp với Google Sheet và hỗ trợ phát thanh viên truyền hình (TV News Broadcast).

## 🚀 Hướng Dẫn Xuất Bản Lên GitHub Pages (1-Click)

1. **Tạo Repository mới trên GitHub**:
   - Truy cập https://github.com/new
   - Đặt tên Repository (ví dụ: `thoi-tiet-viet-nam`).
   - Chọn chế độ: **Public** (Công khai).
   - Nhấn **Create repository**.

2. **Tải tệp lên thư mục gốc (Root)**:
   - Trong trang repo vừa tạo, chọn **Add file** ➔ **Upload files**.
   - Kéo thả trực tiếp 3 tệp: `index.html`, `.nojekyll`, `README.md` (Lưu ý: giải nén file zip trước và kéo thả file lẻ, không tải file .zip lên).
   - Nhấn nút xanh **Commit changes**.

3. **Kích hoạt GitHub Pages**:
   - Vào **Settings** của repository ➔ Chọn mục **Pages** ở thanh menu bên trái.
   - Tại mục **Build and deployment** > **Source**: Chọn **Deploy from a branch**.
   - Tại mục **Branch**: Chọn `main` (hoặc `master`), thư mục `/ (root)`.
   - Nhấn **Save**.

4. **Truy cập**:
   - Đường link chính thức có định dạng: `https://<ten-user>.github.io/<ten-repo>/`

## 🎙️ Lưu Ý Về Giọng Đọc Phát Thanh Viên Tiếng Việt Trên Máy Tính (PC Desktop)

- **Trên Điện thoại (iOS / Android)**: Tích hợp sẵn 100% giọng tiếng Việt chuẩn (Linh, Mai, Google tiếng Việt).
- **Trên Máy tính (PC / Laptop)**:
  - Khuyên dùng **Microsoft Edge** (trình duyệt mặc định có sẵn trên Windows 10 và Windows 11): Edge tích hợp sẵn bộ giọng trí tuệ nhân tạo **Microsoft Hoài My (Chuẩn VTV ⭐)** và **Nam Minh** cực kỳ tự nhiên, truyền cảm.
  - Nếu mở bằng Google Chrome trên PC: Hệ thống đã chặn triệt để việc phát giọng tiếng Anh (Microsoft David). Bạn chỉ cần nhấp chuột phải vào tệp `index.html` ➔ chọn **Open with** ➔ chọn **Microsoft Edge** để nghe giọng phát thanh viên chuẩn VTV.
